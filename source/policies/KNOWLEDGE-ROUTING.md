# Roteamento de conhecimento

## Escopo padrão

O projeto atual é sempre a primeira consulta. Não comece com busca global
irrestrita. Amplie automaticamente para memória global, vault ou projetos
irmãos quando os resultados locais estiverem ausentes ou forem insuficientes.

Todo resultado estrangeiro mantém seu identificador de projeto de origem.
Regras, gotchas, decisões e procedimentos estrangeiros são referências
atribuídas; não são restrições do projeto atual. Não escreva resultados
estrangeiros automaticamente na memória atual. Promoção para memória global é
uma captura deliberada.

## Ordem de confiança

1. Estado e instruções do projeto atual.
2. Memória do projeto atual.
3. Memória global compartilhada.
4. Vault de conhecimento pessoal (opcional).
5. Outros projetos.
6. Web e conhecimento geral, ajustados por atualidade e autoridade.

O vault é indicado para decisões, procedimentos, pesquisa acumulada e
conhecimento cruzado. Fatos temporais devem ser verificados em fonte atual.

ai-memory e o vault são integrações opcionais: use quando detectados/configurados
e continue normalmente quando ausentes, sem bloquear a tarefa. Degradação segura:
sem memória externa, trabalhe com o estado do projeto atual e registre os limites
de verificação resultantes.
