## Orquestração híbrida (Claude + Orca + OpenCode)

- Papéis: Claude coordena (planeja, delega, verifica, decide, conclui); Orca supervisiona (Runs/Tasks/Dispatches, `worker_done`, despertar, retomada); OpenCode executa. Em missão híbrida Claude não implementa: o Orca inicia o primário `build`, que escolhe especialistas e delega toda escrita. Fora de missão, pergunta e leitura são diretas; edição trivial direta só em repo cuja política não exija worker (neste repo exige).
- Modo: pergunta/leitura/edição trivial fora de missão → direto; tarefa simples → OpenCode direto ou 1 worker; missão multi-etapa, longa, paralela ou com revisão independente → híbrido via skill `hybrid-orchestration`. Acione-a sozinho; worker despachado (prompt com Task e Dispatch IDs) não a usa.
- Placement em todo Dispatch: `current` só para leitura ou escritor único em checkout exclusivo; `new-child` para escritores concorrentes ou checkout compartilhado; `new-top-level` para trabalho independente. Fases dependentes reutilizam worktree e branch; retry repete o placement (`--retry-of` não herda). Após cada Dispatch/retry, verifique repo, caminho, branch e base Git reais: parentesco na UI do Orca não prova ancestralidade Git. Sem `--model`.
- Delegue objetivos completos com critérios de aceite objetivos; não repita o planejamento técnico interno dos workers.
- Contrato observável: Dispatch criado → prompt recebido → turno iniciado → progresso → `worker_done` → verificado → integrado → worker liberado → worktree e branch limpos. `worker_done` não é prova; `worker-release` não remove worktree; CI verde não é merge.
- Sucesso reportado não é prova: confronte a evidência com cada critério. Continue até o aceite ou bloqueio real; ações irreversíveis ou fora do escopo exigem confirmação específica.
- Encerramento: PR, checks, merge confirmado, `git pull --ff-only` na base, release, remover só worktrees/branches da missão, limpos. Squash merge não aparece como ancestral: prove pelo estado da PR e pela ausência de commits locais inéditos. Sem `--force`; preserve stashes e trabalho pré-existente/de terceiros.
- Retomada: reconstrua do Orca (`run-current`/`run-list`, `worker-list`, `inbox`); nunca reinicie Dispatch sem prova de não-execução. Sem daemon, polling, fila, kernel ou hook novo sem necessidade comprovada. JEV é opcional e consultivo.
- Fonte canônica: repositório `opencode-orchestration` (`source/claude/`); instalada por `install.ps1 -ClaudeHybrid`. Não edite a cópia instalada.
